# Market Value Hunter — бесплатные уведомления Авито

Windows-приложение читает **вашу собственную почту по IMAP** и показывает прямые ссылки на объявления из писем Авито. В бесплатном режиме нет ключа API.SH, платных запросов, подписки приложения, пробного срока или вызовов ИИ. Никаких запросов к страницам Авито, сбора сессий, обхода CAPTCHA, прокси или обхода защиты нет.

**Это обработчик полученных уведомлений, а не полный поиск по базе Авито.** Без писем от Авито новых результатов не будет. Доступность email-рассылки нужно проверить в своём аккаунте до настройки программы. Обещать бесплатный полный поиск «навсегда», мгновенную доставку или неизменность сторонних сервисов невозможно.

## Скачать и запустить Windows EXE

1. Откройте [Build Windows executable](https://github.com/cheden123/market/actions/workflows/build-windows.yml).
2. Выберите успешный запуск для последнего коммита `main`, скачайте **MarketValueHunter-Windows**, распакуйте ZIP.
3. Запустите `MarketValueHunter.exe`. Python не нужен. В ZIP также есть эта инструкция и SHA256SUMS.txt. EXE не подписан: Windows может показать SmartScreen.

Артефакт сборки хранится в GitHub 30 дней; workflow можно запустить повторно. Для скачивания артефакта GitHub может потребовать вход. Это срок хранения загрузки, а не срок работы приложения.

## Настроить без командной строки

1. На Авито выполните поиск с нужными словами, регионом и ценой. Сохраните поиск, включите уведомления **на email, если такая опция есть в вашем аккаунте**. Убедитесь, что настоящее письмо пришло на вашу почту. Одних push-уведомлений на телефоне недостаточно.
2. В своей почте разрешите IMAP и создайте отдельный **пароль приложения**. Обычный пароль от аккаунта вводить не нужно. Инструкции: [Яндекс: IMAP](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others), [Яндекс: пароли приложений](https://yandex.ru/support/id/ru/authorization/app-passwords), [Mail.ru: подключение почтовой программы](https://help.mail.ru/mail/login/mailer/).
3. Откройте вкладку **Новые из почты**. Выберите Яндекс или Mail.ru, укажите полный адрес почты и пароль приложения. Для другого провайдера укажите IMAP-сервер и TLS-порт (обычно 993); провайдер должен поддерживать IMAP с паролем приложения. OAuth-only аккаунты этим адаптером не поддерживаются.
4. Оставьте папку **INBOX**. Если письма перемещаются правилом, создайте папку с английским названием, например **Avito**, и укажите её здесь. Кириллические имена папок пока не поддерживаются.
5. Нажмите **Проверить подключение**: проверка только входит в почту и открывает папку для чтения, ничего не импортирует. Затем включите автоматические проверки и нажмите **Сохранить настройки почты**.
6. Нажмите **Проверить почту сейчас**. Двойной щелчок по строке открывает объявление в вашем браузере. При автоматических проверках новые строки появляются без всплывающих окон; итог проверки виден внизу окна.

Кнопки проверки вручную используют текущие поля формы; автоматический режим — сохранённые настройки. По умолчанию интервал — 5 минут; допустимо 1–1440. **Оставляйте приложение открытым и компьютер включённым.** После закрытия, сна или выключения проверки прекращаются; при следующей проверке программа продолжает с сохранённого места. Автозапуск Windows и фоновая служба не устанавливаются.

## Что именно получает бесплатный режим

- Письма с адресом отправителя `avito.ru` или его поддоменов из выбранной папки. На сервере используется фильтр FROM, в программе дополнительно проверяется точный домен. Заголовок From может быть подделан: он не доказывает подлинность письма. Программа не заменяет антиспам и проверку отправителя вашей почты.
- Только прямые HTTPS-ссылки на объявления `avito.ru`, `www.avito.ru`, `m.avito.ru`, путь которых заканчивается на `_числовой_ID` (от 5 цифр). Метки отслеживания удаляются. Ссылки через трекеры, переадресации, вложения и изображения не открываются и не разбираются. Письмо может содержать рекомендации или старые объявления, поэтому строка означает «впервые получено программой», а не подтверждённую дату публикации.
- HTML и текстовые письма, включая MIME и обычные кодировки. При первом запуске — последние 7 дней (настраивается до 30). За проверку — до 50 писем от старых к новым; остаток будет прочитан при следующих проверках. Письма больше 2 МиБ пропускаются с отдельным счётчиком, без загрузки тела. Пропущенные большие письма автоматически повторно не импортируются.
- Ссылки сохраняются в SQLite и не дублируются по ID объявления даже после перезапуска, смены папки или повторного письма. UID и UIDVALIDITY отслеживаются отдельно для сервера, порта, аккаунта и папки; при ошибке загрузки курсор не перескакивает через письмо.
- IMAP работает через TLS с проверкой сертификата, папка открывается только для чтения, тело загружается через BODY.PEEK. Письма не удаляются и не помечаются прочитанными. Пароль хранится в Windows Credential Manager через keyring, без копии в config.json и базе. Сохранение с пустым полем удаляет сохранённый пароль; отозвать доступ можно в настройках почты.

**Местные профили поиска и Telegram относятся к анализу JSON, а не фильтрации/рассылке писем.** Для писем задавайте фильтры на Авито. Приложение показывает все подходящие прямые ссылки в отдельной вкладке, даже если из письма нельзя достоверно получить цену или регион. Цена, «рыночная стоимость» и прибыль не угадываются и не используются для отсечения писем.

Если проверка успешна, но новых ссылок нет: проверьте реальное поступление email, папку и период первого импорта. Счётчик «без прямых ссылок» может означать трекерный формат или неподходящее письмо. Нулевой результат **не доказывает**, что на Авито нет новых объявлений. Можно использовать родные уведомления Авито; приложение не превращает push в email.

## Проверка доступных источников и ограничения

Проверено 9 ноября 2026 года:

| Источник | Решение |
|---|---|
| Собственные email-уведомления → IMAP | Реализован бесплатный клиент. IMAP/TLS и пароли приложений подтверждены документацией почтовых провайдеров выше. Наличие писем Авито зависит от аккаунта и рассылки. |
| Сохранённые поиски / родные push Авито | Настраиваются пользователем на сайте или в приложении Авито; программа не считывает push и не входит в аккаунт Авито. |
| Официальный каталог API Авито | [Каталог](https://developers.avito.ru/api-catalog) недоступен из среды проверки; бесплатный разрешённый API общего поиска не подтверждён, поэтому на него не опираемся. |
| RSS, скрытые API, автоматическое чтение страниц | Бесплатный официальный канал не подтверждён; не реализованы. |
| API.SH | Удалён из пользовательского потока GUI. Старые source_api.py / monitor.py оставлены для совместимости и тестов; GUI их не импортирует и не вызывает, даже при старом monitor.enabled=true. |

Официальная [справка Авито](https://www.avito.ru/support) и [условия](https://www.avito.ru/legal/rules/terms-of-use) из среды проверки не открылись. Поэтому текущие пункты интерфейса, доступность email и юридическое разрешение конкретного сценария независимо не подтверждены. Выбран минимальный сценарий: чтение владельцем собственного ящика без автоматического обращения к Авито; это не юридическое заключение. Нужна проверка на реальном письме пользователя: в репозитории используются синтетические примеры, не утверждается совместимость со всеми текущими шаблонами Авито.

Бесплатность здесь означает отсутствие платежей программе и API.SH. Сторонние сервисы могут изменить условия, отключить IMAP или рассылку. Для работы нужны ваша почта, интернет и включённый компьютер; обещания внешних сервисов «навсегда» нет.

## Анализ выгоды, экономия токенов и данные

Вкладка **Оценка выгоды (JSON)** сохраняет существующий импорт объявлений и демо. JSON-массив содержит `source`, `external_id`, `title`, `price`, `url`, необязательные `description`, `region`. Для анализа настройте профили и финансовые пороги. Демо вымышленное. Цены предложений не равны ценам реальных продаж, прибыль приблизительная; состояние и продавца проверяйте самостоятельно.

Чтение почты, удаление дубликатов и статистика не требуют LLM. Локальная Ollama необязательна и выключена по умолчанию; для JSON-анализа ограничена бюджетом и кэшем. Telegram также выключен по умолчанию и настраивается отдельно для сигналов анализа JSON.

Настройки, история и ссылки хранятся в `%LOCALAPPDATA%\MarketValueHunter`. База содержит личные темы писем и ссылки: не публикуйте её. Сырые письма и пароль в базу не записываются. При обновлении прежние данные сохраняются. Ключ API.SH из прежней версии не используется; при необходимости удалите его вручную из диспетчера учётных данных Windows.

## Запуск и проверка из исходников

Нужен Python 3.11+ с Tk:

```powershell
python -m pip install -r requirements-gui.txt
python app_gui.py
python -m unittest discover -s tests -v
python app_gui.py --smoke-test smoke-result.json
```

CLI JSON-анализа: `python hunter.py init`, `python hunter.py ingest example_listings.json`, `python hunter.py report`.

Windows workflow запускает unit-тесты, собирает EXE, запускает именно упакованный GUI с изолированной временной базой и синтетическим письмом, проверяет отчёт, затем публикует EXE с инструкцией и SHA256. Smoke-тест не использует личную почту, системные секреты или сеть. Это проверка сборки и интерфейса, не реальная доставка уведомлений Авито.
